# Arcana · Two-Tone Design Studio Pack

**Based on the approved Arcana style-board and the five IdleArc class-reference screenshots.**

This is a real, importable asset collection, NOT merely a zip containing one preview image.

- `references/approved-style-board.png` — the exact approved concept sheet, preserved unchanged.
- `classes/badges/` — Warrior, Archer, Mage, Rogue, Druid circular emblems, individual editable vector files.
- `classes/glyphs/` — corresponding flat SVG glyphs without badge backgrounds.
- `classes/png-256/` — 256px transparent PNG raster exports for convenient imports.
- `brand/arcana-triangle.svg` — purple faceted triangle.
- `brand/wordmarks/arcana-wordmark.svg` — white uppercase ARCANA header wordmark.
- `brand/header/` — composite triangle + header wordmark, wide and compact (plus PNG).
- `icons/` — individually named two-tone icons for the full Arcana feature set.
- `components/` — reusable cards, chips, badges, buttons and layout examples.
- `tokens/` — exact colors in JSON and CSS.
- `patterns/`, `vectors/`, `previews/` — backgrounds, empty states and overview sheets.

## Important
The design board is a **flattened concept image**. The individual SVGs are newly drawn approximations following its style, not an impossible perfect vector extraction of that flat image. The original board is included for visual reference. The asset pack is intentionally compact because SVG vectors scale to any resolution; padding it to 200 MB would waste space without improving quality.

No live website, repository, or Fandom changes were made.
