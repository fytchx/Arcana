# Psychedelic textures + real-page Theme Studio preview

## Intent
Four **original**, purpose-built vector patterns inspired by the general visual direction of psychedelic illustration, not copies of example screenshots or rendered concept posters.

| Pattern | Structure | Color behavior |
| --- | --- | --- |
| Groove Melt | Periodic sine-ribbon fills | Five explicit solid-color regions |
| Orbit Jelly | Repeated nested wobbly orbit silhouettes | Recolorable nested lobes and outlines |
| Doodle Rift | Tiled comic ink stripes, checks, stipple and stars | Five-color illustrated blocks |
| Prism Puddle | Repeating irregular blob pools with nested contours | Recolorable outlines, highlights and fills |

Patterns are authored in `src/psychedelic-patterns.js` as parameterized SVG geometry, not flattened pictures. The tile is exactly 360×360, with wrapping copies of edge-crossing motifs. Repeating the SVG is intentional; unlike the previous gradient bug, matching opposite edges makes repetition visually seamless.

## How the editor works
- Select a Psychedelic preset or an individual motif from the texture library.
- New **Five-color pattern palette** appears only when a psychedelic texture is active: background, primary, secondary, accent and outline.
- Palette source **My five colors** keeps exact custom colors. **Match website colors** follows the current theme palette.
- **Outline weight** and all existing texture scaling/intensity controls remain adjustable.
- Preview artwork swatches and real site surfaces are generated by the same parameterized SVG program.
- Existing 38 presets remain; four additional presets bring the total to 42. The texture library now holds 88, including all existing 84.

## Live preview is the real current site
The small legacy hand-drawn mini preview was stale. The visible preview now uses a read-only same-origin iframe on actual Arcana routes, with a DOM-only styling overlay from the parent editor. It shows the active source version of Home, Build Studio, Pathfinder, Wiki, Profile and Guilds. It does **not** change account roles, write database fields, modify browser storage or publish a draft. The older mini remains hidden in markup until removal is proven safe for legacy checks.

Phone / tablet / desktop toggles resize the true viewport before scaling it into the dock. Before / After switches the applied style baseline, while preserving the same actual site layout.

## Safety, delivery and verification
- Drafts are local and undoable. Admin publishing remains restricted to the existing permission checks.
- All work lives in a feature branch and is deployed only to the isolated Arcana Preview App after source and Android browser QA.
- Use `npm run check`, `tests/psychedelic-theme-editor.test.mjs` and `tests/mobile_smoke.py` to verify all color slots, tile edge geometry, actual current-page iframe and mobile layout.
- No production publication, game mechanics, or data-mine edits are part of this task.
